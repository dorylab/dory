## What's Changed

### Improvements
- Upgraded Next.js across the web and admin apps, enabling configurable instant navigation for faster page transitions.
- Refactored AI-related application workflows—including chatbot message rendering, streaming endpoints, and agent logic—to improve consistency and maintainability of AI interactions.

### Fixes
- Disabled standalone output in Next.js configuration to ensure compatibility with Vercel deployments.
- Updated `electron-builder` keychain signing configuration to resolve signing issues during Electron app builds.

### Dependencies
- Bumped `fflate` from `0.4.8` to `0.4.9` for improved compression reliability.
- Upgraded `nanoid` from `5.1.16` to `6.0.0`, adopting breaking changes aligned with modern ID generation practices.
