## What's Changed

### Features
- Added Docker Compose support with `docker-compose.yml` and related environment configuration (`docker-compose.env.example`), simplifying local and production deployments.
- Introduced compatibility for legacy chat message formats, ensuring smooth migration and backward compatibility in chat threads.
- Moved organization-level settings (AI, billing, general) into a unified, accessible settings dialog—improving UI consistency and user navigation.

### Improvements
- Refactored AI chat infrastructure to use `ToolLoopAgent`, enabling more robust, iterative tool execution and better handling of complex multi-step tasks (e.g., SQL generation, chart building, RAG).
- Shared and standardized MCP and AI tooling across chat endpoints and clients—reducing duplication and improving maintainability of SQL, chart, and Dory-specific tools.
- Updated chat tool prompts, rendering logic, and i18n strings (English, Spanish, Japanese, Chinese) for improved clarity, localization, and UX during tool invocation and display.

### Fixes
- Improved connection handling and database/table metadata APIs by refactoring shared connection helpers and driver runtimes—resolving inconsistencies in previews, DDL, stats, and schema introspection endpoints.

### Internal
- Updated Dockerfile and deployment scripts to align with new compose-based workflows.
- Consolidated type definitions, test utilities, and i18n asset management across packages to support cross-app tooling and settings unification.
