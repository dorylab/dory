## What's Changed

### Features
- Introduced the **Dory Import Wizard**, a new guided interface for importing data with support for Parquet, NDJSON, and Arrow file formats.
- Added **import write capabilities** across multiple database drivers (ClickHouse, Cloudflare D1, DuckDB, MySQL, Oracle, PostgreSQL, SQL Server, SQLite), including partial-write feedback during ingestion.
- Enabled **paginated listing of import runs**, improving navigation and scalability for users with many import jobs.

### Improvements
- Enhanced **import reanalysis flow** and stabilized table preview selection in the data preview component.
- Improved **import navigation and status styling**, with clearer visual cues for import progress and outcomes.
- Standardized **import plans** to align more closely with source-specific options, improving consistency and predictability.
- Preserved **connection form fields when switching driver types**, reducing user effort during connection setup.
- Refined **SQL Console workflows**, including clipboard editing enhancements and improved result table interactions.

### Fixes
- Fixed error sanitization during imports to prevent sensitive or unhandled errors from leaking to the UI.
- Resolved issues with hidden window behavior in the Electron app, ensuring windows show without stealing focus.

### Internal
- Extended database schema with new `import_transform_stats` migration to support richer import analytics.
- Updated i18n files with new and revised translation keys for import-related UI elements.
- Refactored core application workflows across web and Electron apps to improve maintainability and consistency.
