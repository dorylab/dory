## What's Changed

### Features
- **Artifact integration in Agent Runs**: Artifacts and persisted findings are now displayed directly on agent run detail and list pages, improving traceability between agent executions and their generated outputs.

### Improvements
- **Artifact metadata and usage display**: Refreshed artifact list UI with updated metadata, retention indicators, and usage context—localized for English, Spanish, Japanese, and Chinese.
- **ClickHouse command support**: Command statements (e.g., `CREATE TABLE`, `DROP DATABASE`) now execute correctly without attempting result-set formatting, improving reliability for DDL/DML operations.

### Fixes
- **Stricter artifact evidence requirement**: Agent Run findings now require associated Artifact evidence, enforcing data integrity and preventing orphaned or unverifiable results.

### Internal
- **Dependency updates**: Upgraded core dependencies across the stack:
  - Next.js bumped from `16.2.7` to `16.2.11` (in `apps/web`, `apps/admin`, `packages/i18n`, and `packages/web-utils`)
  - Hono upgraded to `4.13.1`, `@hono/node-server` to `1.19.17`, `pacote` to `21.5.1`, and `postcss-selector-parser` to `7.1.5`
- **Docker build enhancements**: Export and schema-compare packages are now included in Docker images, ensuring full CLI tooling availability in containerized deployments.
