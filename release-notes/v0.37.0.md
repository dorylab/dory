## What's Changed

### Features
- **Artifact management**: Added full artifact saving, viewing, and workspace integration—including pinning, retention filtering, creator attribution, and improved metadata display.
- **SQL result persistence**: Restored active SQL result sets during work hydration and introduced initial result targets for better continuity across sessions.
- **Chart controls**: Moved chart saving functionality into the chart control bar for more intuitive visualization workflows.

### Improvements
- **UI/UX enhancements**:  
  - Added help and community links to the app sidebar.  
  - Introduced SQL editor preview and configurable panel height in settings.  
  - Improved selection guidance and styling across tables, connections, and dialogs.  
  - Simplified artifact pin controls and removed redundant padding in artifact groups.  
- **Workspace isolation**: Enabled artifact workspace tab isolation for cleaner context switching between artifacts and SQL consoles.

### Fixes
- Fixed vtable filter draft application logic to ensure filters apply correctly before submission.

### Internal
- Updated multiple dependencies including `postcss` (8.5.10 → 8.5.23), `mermaid` (11.15.0 → 11.16.1), `js-yaml` (4.3.0 → 4.3.1), `fast-uri` (3.1.2 → 3.1.5), `brace-expansion` (1.1.16 → 1.1.18), `form-data` (4.0.5 → 4.0.6), and `tmp` (0.2.6 → 0.2.7).
