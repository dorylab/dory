## What's Changed

### Features
- **Live SQL result preview**: The SQL console now displays planned result set schemas (column names and types) while a query is still executing, improving visibility into expected output before full results arrive.

### Fixes
- **Query execution stability**: Resolved an issue where incomplete or malformed result metadata could cause rendering errors during live query execution.

### Internal
- Updated test coverage for result loading states and snapshot handling.
- Adjusted CI workflow configuration to align with new beta release practices.
