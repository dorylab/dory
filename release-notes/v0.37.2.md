## What's Changed

### Improvements
- **Artifact navigation and context**: Organized artifacts under a collapsible "More" sidebar menu for cleaner UI. Preserved agent run context when viewing individual artifacts, improving workflow continuity.
- **Artifact titles and evidence handling**: Improved artifact title generation and now require explicit finding evidence—enhancing clarity and reliability of artifact metadata.

### Fixes
- **Agent Workspace execution results**: Consolidated and standardized how SQL execution results are hydrated and displayed in the Agent Workspace, reducing inconsistencies and improving result fidelity.

### Internal
- **Dependency updates**: Updated several dependencies including `browserslist`, `nanoid`, `@faker-js/faker`, `@humanfs/node`, `qs`, `@xmldom/xmldom`, and `fast-uri` to their latest patch/minor versions for security, stability, and compatibility.
